# sweepwatch-data

Published street sweeping datasets for the SweepWatch app.

This repository holds build output only. Nothing here is edited by hand, and there is no
source code: everything is generated by the `publish-dataset` workflow in the SweepWatch
repository and pushed here so the app has somewhere unauthenticated to fetch from.

## What is here

| File | |
|---|---|
| `manifest.json` | What the current dataset is: schema version, SHA-256, size, build time, and the URL of the file itself |
| `sweep-<sha12>.sqlite` | The dataset, named by the first 12 characters of its digest |

Datasets are content addressed and never overwritten. Only `manifest.json` changes in place,
which means a client that has already started a download cannot have the file move underneath
it, and an older app build can keep fetching a dataset it knows how to read.

## How the app uses it

The app reads `manifest.json`, compares the digest against what it has installed, and stops
there if they match. If they differ it checks the schema version *before* downloading
anything, since an app that reads a newer layout as though it were the old one produces
confident, wrong answers about which side of the street to park on. After downloading it
verifies size and digest, confirms the file actually opens as a dataset, and only then swaps
it in. Any failure leaves the previous dataset in place: stale data is recoverable, wrong
data is a parking ticket.

## Source and licence

Derived from the San Francisco street sweeping schedule published by DataSF as dataset
`yhqp-riqs`, which is released under the Public Domain Dedication and License (PDDL). The
transformation into the packed format described above is part of SweepWatch.

This data is provided as-is and with no guarantee of accuracy. Posted signs are the
authority, not this file.
